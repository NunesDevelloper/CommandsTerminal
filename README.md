# Command's Terminal

## description:

The Command's Terminal it's a game where you have to solve a problem using the terminal, typing commands to solve the problem.

You go win ?

Test your console skills and have fun with this game.

## Frequently Asked Questions
Do I need to know anything about the terminal to beat this game?

- No, this game is for testing and learning commands used by IT professionals or advanced users.

Which terminals does this game cover?

- Well, it will cover the Windows, Mac, Linux (Debian/Arch) terminals and some tools like Git and Docker.

Is this an educational game?

- Yes, but it's quite fun.
